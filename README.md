# Звуковой пульт (SoundDeck)

Куда и как громко звучит каждая программа, в одном окне у часов.

## Как пользоваться

Щелчок по значку в трее (три фейдера) или **Ctrl+Alt+D** открывает пульт:

* **Вывод.** Все устройства с громкостью и индикатором. Щелчок по устройству
  делает его основным. Звёздочкой отмечаются устройства для быстрого
  переключения (по умолчанию наушники и колонки), кнопка вверху переключает
  между ними.
* **Программы.** У каждой своя громкость, индикатор и кнопка «без звука».
  Кнопка «По умолчанию ▾» выбирает, **куда идёт звук этой программы**:
  Discord в наушники, игра в колонки. Windows запоминает выбор, пульт тоже:
  если устройство отключали, назначение вернётся, когда программа снова
  заиграет.

Ползунки двигаются мышью и колёсиком.

## Горячие клавиши

| Клавиши | Что делают |
|---|---|
| Ctrl+Alt+S | наушники ↔ колонки (между отмеченными звёздочкой) |
| Ctrl+Alt+↑ / ↓ | громкость активной программы ±5% |
| Ctrl+Alt+M | выключить или включить звук активной программы |
| Ctrl+Alt+D | открыть пульт |

Внизу экрана коротко показывается, что изменилось. Клавиши и шаг громкости
меняются в `%LOCALAPPDATA%\SoundDeck\settings.json` (раздел `Hotkeys`,
`VolumeStepPercent`), после правки нужно перезапустить пульт. Если клавишу
уже заняла другая программа, это видно в меню значка.

`SwitchCommunications` (по умолчанию включено): при переключении меняется и
устройство для звонков, иначе Discord, Teams и подобные останутся на старом.

## Установка

`%LOCALAPPDATA%\Programs\SoundDeck\SoundDeck.exe`, автозапуск через
`HKCU\...\Run` (выключается в меню значка). После падения пульт сам
перезапускается, не больше трёх раз за 10 минут.

Назначения программ хранит Windows: их видно в «Параметры → Звук →
Микшер громкости». Пункт меню «Вернуть все программы на устройство по
умолчанию» сбрасывает их все.

## Как это устроено

Громкость программ и устройств идёт через Core Audio (WASAPI). Выбор
устройства для программы делается недокументированным
`Windows.Media.Internal.AudioPolicyConfig`, тем же, что использует сам
микшер Windows и EarTrumpet. Устройство по умолчанию меняется через
`IPolicyConfig`.

## Сборка

```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

Проверка без интерфейса:

```
SoundDeck.exe --list report.txt
SoundDeck.exe --route telegram "Динамики" report.txt   (или default)
SoundDeck.exe --default "Наушники" report.txt
SoundDeck.exe --render panel.png
SoundDeck.exe --hotkeys report.txt
```
